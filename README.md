# Policy & Rule Change Tracking System

A comprehensive database management system designed to track, version, and govern organizational policies. This project provides a robust Oracle SQL schema to handle the entire lifecycle of a policy, from drafting and approval to version control and archiving. It also includes a web based dashboard to visualize the Entity Relationship diagram, database tables, and SQL queries.

### Key Features
* Entity Relationship Diagram representing a 3NF normalized schema.
* Complete Oracle SQL implementation including DDL, DML, and 20 business logic queries.
* Interactive web dashboard built with HTML, CSS, and JavaScript to showcase the project architecture and data.
* Role based access and department categorization for policies.

### Repository Structure
* **database** : Contains the core Oracle SQL script for schema creation, data insertion, and queries.
* **web** : The source code for the interactive project dashboard.
* **docs** : Project documentation including the final report and ER diagram.

### Getting Started
To run the web dashboard, simply open the index.html file located in the web folder in any web browser.
To explore the database, execute the SQL script located in the database folder in any Oracle SQL compatible environment.
